# tg_for_maria
Бот для Жинки ❤️

Это милый, заботливый и функциональный Telegram-бот, созданный специально для второй половинки. Он умеет делать комплименты, подкидывать идеи для свиданий, заботиться о погоде и помогать с рутинными задачами (например, честно выбирать, кто моет посуду!).

---

## 🌟 Основной функционал

Бот поддерживает множество уютных функций:

*   **Ежедневные комплименты (`/compliment`)** — можно подписаться на комплимент в определенное время. Бот присылает теплые слова и подкрепляет их милой картинкой. Можно загрузить свои личные фото просто отправив их боту!
*   **Забота о погоде (`/weather`, `/set_city` и `/weather_sub`)** — показывает погоду (текущую и на день) и дает советы: одеться теплее или взять зонт. Город можно настроить через `/set_city` (поддерживается автоматический поиск координат городов!). Можно подписаться на утреннюю сводку.
*   **Трекер настроения (`/mood`, `/mood_history` и `/mood_sub`)** — вечером бот может спросить, как прошел день. Если настроение плохое (оценка 1-2), он постарается утешить милой картинкой и словами поддержки. Оценки сохраняются, и их можно посмотреть через `/mood_history` за последние 7 дней.
*   **Идеи для свиданий (`/date_idea`)** — генерирует случайную идею для уютного вечера вдвоем, если вы не знаете, чем заняться.
*   **Честный выбор (`/roll`)** — решает споры (например, "кто моет посуду?"). Встроен алгоритм "справедливой рулетки", чтобы один человек не выпадал три раза подряд!
*   **Напоминания (`/remind` и `/list`)** — возможность создавать разовые, ежедневные или еженедельные напоминания для обоих пользователей.

## 🛠️ Технологический стек
*   **Язык**: Python 3.11+
*   **Фреймворк**: aiogram 3.x
*   **База данных**: SQLite3 (используется для сохранения подписок, настроек пользователей, истории настроения и пользовательских фотографий)
*   **Развертывание**: Docker (написан Dockerfile) / Polling / Webhooks

## 🚀 Как запустить (Локально)

1. Клонируйте репозиторий и создайте виртуальное окружение:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` в корневой папке и укажите токен:
   ```ini
   BOT_TOKEN=ваш_токен_от_BotFather
   RUN_MODE=polling
   ```
4. Запустите:
   ```bash
   python3 main.py
   ```

## ☁️ Развертывание (justrunmy.app)

Для деплоя через Docker на платформу justrunmy.app или аналогичную, достаточно просто привязать репозиторий. Бот автоматически соберется благодаря `Dockerfile`.

**Важно:** Не забудьте в панели управления вашего хостинга указать переменную среды `BOT_TOKEN` (токен вашего бота).
