# tg_for_maria
Бот для Жинки ❤️

Это готовый каркас Telegram-бота на асинхронной библиотеке `aiogram` (версии 3.x), спроектированный для работы в двух режимах: локального тестирования (через Polling) и постоянного хостинга в облаке (через Webhook) без необходимости держать включенным ваш ноутбук.

## 🛠️ Как это устроено

Бот может работать в двух режимах, переключение происходит через файл `.env` (переменная `RUN_MODE`):
1. **Polling (Локально)**: Бот сам опрашивает сервера Telegram. Удобно для разработки.
2. **Webhook (В облаке)**: Бот запускает легковесный веб-сервер. Telegram сам отправляет новые сообщения на этот адрес. Идеально для деплоя на бесплатные платформы (например, **Render**), чтобы бот работал круглосуточно.

## 💻 Локальный запуск (разработка на компьютере)

Для запуска бота локально выполните следующие шаги:

1. **Создайте виртуальное окружение и активируйте его:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте переменные окружения:**
   Скопируйте пример файла конфигурации:
   ```bash
   cp .env.example .env
   ```
   Откройте `.env` в текстовом редакторе и вставьте ваш токен бота, полученный от [@BotFather](https://t.me/BotFather):
   ```ini
   BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
   RUN_MODE=polling
   ```

4. **Запустите бота:**
   ```bash
   python main.py
   ```
   Бот напишет в консоли `Starting bot in long polling (local) mode...`. Напишите ему в Telegram — он должен отвечать и повторять ваши сообщения.

## ☁️ Размещение в облаке на 24/7 (без ноутбука)

Самый простой и бесплатный способ запустить этого бота круглосуточно — это хостинг **Render.com**.

### Шаг 1. Отправьте изменения в ваш GitHub-репозиторий
Убедитесь, что все созданные файлы отправлены в ваш GitHub-репозиторий:
```bash
git add .
git commit -m "Add bot skeleton with polling and webhook support"
git push origin main
```
*(Токен бота в файле `.env` не попадет на GitHub благодаря настроенному `.gitignore`)*.

### Шаг 2. Создайте аккаунт и Web Service на Render
1. Зарегистрируйтесь на сайте [Render.com](https://render.com/) (можно войти через GitHub).
2. На панели управления нажмите кнопку **New** -> **Web Service**.
3. Подключите ваш GitHub-аккаунт и выберите репозиторий `tg_for_maria`.
4. Настройте параметры веб-службы:
   * **Name**: `tg-for-maria` (или любое другое название)
   * **Environment**: `Python 3`
   * **Region**: Выберите любой (например, Frankfurt)
   * **Branch**: `main`
   * **Build Command**: `pip install -r requirements.txt`
   * **Start Command**: `python main.py`
   * **Instance Type**: `Free`

### Шаг 3. Добавьте переменные окружения в Render
Нажмите на вкладку **Environment** в настройках вашей веб-службы на Render и добавьте следующие переменные (Environment Variables):

| Key | Value | Описание |
| :--- | :--- | :--- |
| `BOT_TOKEN` | *ваш_токен_от_botfather* | Токен вашего бота |
| `RUN_MODE` | `webhook` | Режим работы через вебхуки |
| `WEBHOOK_HOST` | `https://tg-for-maria.onrender.com` | Ссылка, которую Render выделит вашему сервису (будет отображаться вверху панели управления Render) |

После сохранения переменных Render автоматически запустит сборку и развертывание вашего бота. Бот зарегистрирует свой вебхук в Telegram и начнет отвечать пользователям 24/7!

> 💡 **Примечание по бесплатному тарифу Render:**
> Если к боту долго никто не обращается (около 15 минут), бесплатный сервер Render "засыпает". Однако, как только кто-то отправит сообщение вашему боту в Telegram, Telegram отправит запрос на вебхук, сервер Render проснется (это может занять 30-50 секунд при первом запросе) и обработает сообщение. Все последующие сообщения будут обрабатываться мгновенно.
